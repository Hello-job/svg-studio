# 已知问题与待完善功能

适用版本：v0.1.0。以下问题通过代码核查与 Chromium 中的实际编辑流程确认；“已提供入口”不代表所有边界都已完善。

## 优先修复

### 1. 部分属性修改未触发草稿保存

**影响：刷新可能丢失最近的修改。**

从刚载入的示例文档中选择圆形，修改 X 坐标并提交。位置已经变化、撤销记录已经生成，但标题可能仍没有修改标记，界面仍显示“就绪”；此时刷新可能恢复旧内容。

`EditorSession.attribute()` 使用的固定引擎方法只写历史，不发出 `changed`；界面草稿写入依赖 dirty/revision，因此部分属性通路没有同步。撤销到保存点、恢复草稿后的“已保存”基准也尚未完整建模。

临时措施：修改后主动点击“保存 SVG”，保留下载文件，不将本机草稿视为唯一备份。

### 2. 多选方向键移动覆盖对象各自的 transform

**影响：多选对象可能跳动或改变相对位置。**

分别移动两个对象，让它们拥有不同的 transform；Shift 多选后按方向键。当前几何修改会从一个对象生成矩阵，再把同一矩阵应用于整个选区。

临时措施：避免对具有不同变换的多选对象使用方向键，逐个调整并检查结果。

## 其他已确认问题

| 问题                           | 复现与影响                                                                                     | 临时措施                                                      |
| ------------------------------ | ---------------------------------------------------------------------------------------------- | ------------------------------------------------------------- |
| 星形/六边形未完整继承绘图外观  | 无填充时插入星形，可能得到 fill=none、stroke=none 的不可见对象；插入还会把缩放重置为 100%      | 插入前设置可见填充，插入后核对外观与缩放                      |
| 节点删除快捷键缺少上下文       | 选择路径节点后按 Backspace/Delete，不会像“删除节点”按钮那样删除节点                            | 使用节点属性面板中的按钮                                      |
| SVG 样式和物理单位不能无损保留 | `<style>` 中的 class 样式会被移除；mm/cm 等长度没有正确转换，最终尺寸也受引擎 viewBox 处理影响 | 保留原始文件，优先使用 px、viewBox 和直接外观属性，导入后核对 |

导入兼容性需要在安全边界内改善，不能通过放开脚本、HTML 或外部资源来解决。

## 尚未提供的功能

- 可视化线性/径向渐变编辑与可复用色板。
- 路径布尔运算、连接/拆分、文字转轮廓和更完整的节点控制。
- 智能参考线、网格吸附、拖动参考线。
- 图层拖拽排序、分组树折叠与真正的层级管理；已有顶部对象排序菜单。
- 完整多行文字排版、行距、字距、字体上传。
- PNG/JPEG 图片插入入口；SVG 中的合规内嵌位图引用与此不同。
- PNG 倍率、DPI、背景和选区导出选项。
- 多文档/最近文件、多画板、协作、云端文件库。
- 稳定的 React 组件发布接口、宿主通信 API 与完整引擎销毁/多实例隔离。

## 验证边界

目前浏览器实测使用 Chromium。Safari、Firefox、中文输入法完整组合输入、触控笔、多点手势和大型 SVG 性能尚未完成专项验证，不能把这些未验证项当成已发现故障，也不能宣称完全兼容。

单元测试主要覆盖输入清理、快捷键解析、草稿格式、数值字段提交与主题偏好，不覆盖完整的真实引擎工作流。上述缺陷在单元测试通过时仍可能存在。
