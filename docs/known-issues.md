# 已知问题与功能边界

适用版本：v0.1.0，当前仍为实验版本。

## 已确认问题

| 问题                       | 影响与临时措施                                                                                                     |
| -------------------------- | ------------------------------------------------------------------------------------------------------------------ |
| **属性修改未触发草稿保存** | 修改坐标等属性后可能仍显示“就绪”，刷新会回退。部分通路未同步 dirty/revision，请主动下载 SVG。                      |
| **多选变换被覆盖**         | 对拥有不同 transform 的对象多选后按方向键，可能改变相对位置。暂时逐个调整。                                        |
| 星形/多边形不可见          | 无填充时插入可能同时没有描边，并重置缩放。插入前设置可见填充，之后核对外观。                                       |
| 节点删除快捷键无效         | Backspace/Delete 未按节点模式处理，请使用“删除节点”按钮。                                                          |
| SVG 导入有损               | class 样式、物理单位、字体和复杂滤镜可能改变；脚本、HTML、动画、样式表及外部资源会移除。保留原始文件，导入后核对。 |

草稿只保留当前来源下最近一个文档，不保存撤销栈；清理站点数据会清除草稿。`localhost` 与 `127.0.0.1` 不共享存储。撤销到保存点、恢复草稿后的保存基准也尚未完整处理。

## 尚未支持

- 渐变编辑、布尔运算、文字转轮廓、完整节点控制、吸附与智能参考线。
- 图层树与拖拽排序、完整文字排版、字体上传、位图插入入口。
- PNG 倍率/DPI/背景/选区导出、多文档、多画板、协作与云端文件库。
- npm 组件、宿主通信 API、完整引擎销毁与同页多实例；详见[引擎说明](engine.md)。

## 验证范围

Chromium 已实测绘图、主题、属性、节点、历史、菜单与 SVG/PNG 导出。单元测试覆盖导入清理、快捷键、草稿格式、数值字段和主题偏好，不是完整的引擎端到端测试。

Safari、Firefox、完整输入法组合输入、触控笔、多点手势和大型 SVG 性能尚未完成专项验证。引擎独立延迟加载，构建仍有约 1.1 MB chunk 的体积提示。

贡献与反馈方式见 [README](../README.md)。
